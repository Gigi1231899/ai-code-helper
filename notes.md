注入qwenChatModel这个Bean

```java
@Service
@Slf4j
public class AiCodeHelper {
//    @Autowired
//    private ChatModel chatModel;
    @Resource
    private QwenChatModel qwenChatModel;

/**
 * 聊天方法，接收用户消息并返回AI回复
 * @param msg 用户输入的消息
 * @return AI返回的消息文本
 */
    public String chat(String msg) {
        // 将用户输入的消息转换为UserMessage对象
        UserMessage userMessage = UserMessage.from(msg);
        // 调用聊天模型获取AI回复
        ChatResponse response = qwenChatModel.chat(userMessage);
        // 从响应中获取AI消息
        AiMessage aiMessage = response.aiMessage();
        // 记录AI输出日志
        log.info("AI输出：" + aiMessage.toString());
        // 返回AI消息的文本内容
        return aiMessage.text();

    }
}
```

    ↓

    ↓

public class RagConfig {
    @Resource
    private EmbeddingModel qwenEmbeddingModel;

    @Resource
    private EmbeddingStore<TextSegment> embeddingStore;

    @Bean
    public ContentRetriever contentRetriever() {

//        文档切割，按照段落分割，字符数量约束，1000，重叠200

                documentSplitter(documentByParagraphSplitter).

                embeddingStore(embeddingStore).
                build();
        ingestor.ingest(documents);

//        内容检索器
        EmbeddingStoreContentRetriever retriever=EmbeddingStoreContentRetriever.builder()
                .embeddingModel(qwenEmbeddingModel)
                .embeddingStore(embeddingStore)
                .maxResults(5)
                .minScore(0.75)
                .build();
        return retriever;
    }
}

## 三种注入方式对比

### 1. 字段注入（Field Injection）— 最常用但不推荐

java

@Configuration
public class AiCodeHelperServiceFactory {
    @Resource  // 或者 @Autowired
    private ChatModel qwenChatModel;  // ← 需要专门写一个字段

    @Bean
    public AiCodeHelperService aiCodeHelperService() {
        // 直接使用 qwenChatModel
    }

}

**优点**：简洁  
**缺点**：不便于单元测试，依赖隐式

### 2. 构造方法注入（Constructor Injection）— 推荐

java

@Configuration
public class AiCodeHelperServiceFactory {
    private final ChatModel qwenChatModel;

    public AiCodeHelperServiceFactory(ChatModel qwenChatModel) {  // ← 构造方法参数
        this.qwenChatModel = qwenChatModel;
    }
    
    @Bean
    public AiCodeHelperService aiCodeHelperService() {
        // 使用 this.qwenChatModel
    }

}

**优点**：便于测试，依赖显式，支持 `final` 不可变  
**缺点**：代码稍微多一点

### 3. 方法参数注入（Method Parameter Injection）— 你现在的写法

java

@Configuration
public class AiCodeHelperServiceFactory {
    @Bean
    public AiCodeHelperService aiCodeHelperService(ContentRetriever contentRetriever) {
        // 直接在方法参数里声明依赖
    }
}

**优点**：最简洁，不需要额外字段  
**缺点**：只能在 `@Bean` 方法中使用
